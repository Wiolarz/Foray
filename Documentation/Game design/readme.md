# Core of Foray Game Design
Foray is a turn based strategy game most closely reassembling "Heroes of Might and Magic" with "Chess" combat system.
Key design points are tiered by their relevance, starting with the most important "S Tier":
1. Lack of any randomness
2. Perfect information
3. Minimal use of numbers

A Tier
1. Asymmetric gameplay
2. No draws

B Tier
1. Unique Faction identity
2. City progression
